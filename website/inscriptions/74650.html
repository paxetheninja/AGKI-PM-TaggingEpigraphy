AI Analysis Summary

This inscription from Mytilene is a technical building contract (syngraphe) for an architectural project, likely a temple given the mention of a 'sekos' (cella), 'prodomos' (pronaos), and 'opisthodomos'. It provides precise instructions for clearing foundations, the types of stone to be used (poros), the exact dimensions of the blocks in cubits and palms, and the tools required for precision (rule and level). It also establishes the wage for the contractor at eight obols per cubit. The text is fragmentary with several lacunae but the technical instructions remain largely legible.
